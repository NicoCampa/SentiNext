What It Is
==========

SentiNext is an AI-powered SaaS platform that ingests Steam game reviews and
automatically classifies them using LLMs (Google Gemini, with xAI Grok as
fallback) into a structured taxonomy of 30+ subcategories. Instead of manually
reading thousands of reviews, game developers get data-driven dashboards,
reports, and an AI chat interface to understand player feedback.


Who It's For
============

- Indie game developers — overwhelmed by review volume, need to prioritize fixes
- Studio product managers — need quantitative feedback data for leadership
- Community managers — want ground-truth sentiment beyond the vocal minority
- Publisher portfolio managers — need to benchmark across multiple titles


Key Features
============

Dashboard
  Search any Steam game, configure analysis, view category breakdowns, top
  issues/requests, sentiment trends.

Review Explorer
  Full-text search across all analyzed reviews with 20+ filters, CSV export.

AI Chat Agent
  Natural language queries about review data with 14 specialized tools,
  citations, and chart generation.

Game Comparison
  Side-by-side analysis of 2 games with AI-powered comparison summaries.

PDF Reports
  Executive summaries with monthly filtering, player segment analysis, risk
  metrics.

Evidence Extraction
  LLM pulls verbatim player quotes supporting each classification.

Real-time Progress
  SSE-based tracking of analysis progress.

Multilingual
  UI in English, Italian, French, German.

The classification taxonomy covers: technical/, gameplay/, content_design/,
ui_ux_accessibility/, monetization_value/, presentation/, onboarding/,
online_community/, developer_updates/, and more.

Tech Stack
==========

Frontend:  Next.js 16, TypeScript, Tailwind CSS v4, Chart.js, Clerk auth
Backend:   FastAPI (Python 3.11), SQLAlchemy 2.0, PostgreSQL
LLM:       Google Gemini (primary), xAI Grok (fallback)
Infra:     Render (backend Docker + frontend Node), Vercel (marketing site),
           Redis (caching/queues), Sentry (monitoring)
Billing:   Stripe subscriptions + webhook handling


Deployment
==========

Three services: a marketing site on Vercel (web/), the Next.js app frontend on
Render, and a Dockerized FastAPI backend on Render with PostgreSQL. Also supports
local/desktop development mode with no auth required.
