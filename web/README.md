# SentiNext Website

Marketing site for the SentiNext desktop app (local-first Steam review intelligence).

## Pages
- `/` – Landing page
- `/download` – Download instructions (links to GitHub Releases)
- `/docs` – Quickstart + product notes

## Local dev
```bash
cd web
npm install
npm run dev
```

## Build
```bash
cd web
npm run build
npm run start
```
